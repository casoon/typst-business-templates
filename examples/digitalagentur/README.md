# Digitalagentur – example project

**Pixelwerk Digitalagentur**, a web agency in Cologne: web design, development, e-commerce.
Branding: orange accent (#FF6B35), font Inter.

How to compile: see [examples/README.md](../README.md).

| Document | Source | Content |
|----------|--------|---------|
| Invoice | `documents/invoices/2025/invoice.json` | Website relaunch for Zimmermann Schreinerei, 12,066.60 EUR incl. 19 % VAT |
| Offer | `documents/offers/2025/offer.json` | Shopware shop for Hofbauer's Biohof, 9,791.32 EUR incl. VAT, valid 30 days |
| Credentials | `documents/credentials/2025/credentials.json` | WordPress, FTP, database and e-mail access |
| Concept | `documents/concepts/2025/concept.typ` | Online shop concept, written in Typst |
| Documentation | `documents/documentation/2025/documentation.typ` | WordPress user manual, written in Typst |

Each JSON file has a `.typ` file of the same name next to it that passes the data to the template.
