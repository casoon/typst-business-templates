## How they are built

These templates take metadata as parameters of a `#show:` rule and the content as ordinary Typst
text below it. Title page with logo, title, document number, metadata and tags come from
`templates/common/title-page.typ`; branding and labels follow `company.json`. Most have an optional
table of contents (`show_toc`), and all take `show-title-page` and `show-footer`.

```typst
#import "@local/business-templates:0.4.1": protocol

#show: protocol.with(
  title: "Projekt Kick-off Meeting - API Migration",
  document_number: "PROT-2025-001",
  meeting_date: "02.01.2025",
  location: "DataFlow Analytics AG, Konferenzraum 3",
  moderator: "Max Mustermann (IT-Consultant)",
  participants: ("Dr. Sarah Schmidt (DataFlow Analytics AG, CTO)", "Michael Berger (DataFlow Analytics AG, Lead Developer)"),
  company: json("/data/company.json"),
)

= Begrüßung und Agenda

Dr. Schmidt eröffnet das Meeting …
```

## Task list

<Sample slug="task-list" name="task list" />

The one template here that is called as a function, not a show rule: you pass `categories:` with
`tasks:`. Each task has status, priority, due date, assignee, tags and subtasks; dependencies are
supported, too.

**Suggestion:** keep the tasks in data and render the list for a sprint review or a client report.
